\# 🚀 Python Practice \& Git Workflow Sandbox



Created by Saksham Singh.



This repository is a showcase of building Python applications using an enterprise-grade Git workflow. It demonstrates feature branching, Pull Requests, merge conflict resolution, and integrating AI as a pair programmer and automated code reviewer.



\## 🛠️ Features

\* \*\*CLI To-Do App (`todo.py`):\*\* A command-line task manager with persistent JSON data storage, automated error handling, and data validation.

\* \*\*Weather Fetcher (`weather.py`):\*\* A script that queries the Open-Meteo REST API to fetch and display real-time temperature data based on geographic coordinates.



\## 💻 Technologies \& Tools Used

\* \*\*Language:\*\* Python 3

\* \*\*Version Control:\*\* Git, GitHub 

\* \*\*Workflow:\*\* Feature Branching, Pull Requests, Merge Conflict Resolution

\* \*\*AI Integration:\*\* Code Generation, Automated PR Reviews (CodeRabbit)
